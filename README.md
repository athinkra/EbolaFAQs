# EbolaFAQs
Translations of FAQs about Ebola developed for the Bundibugyo outbreak of 2026 in the Democratic Republic of Congo and Uganda.
FAQs produced for the Uganda outbreak of Sudan ebolavirus in 2022-2023 may be found at: https://github.com/enabling-languages/uganda-ebola-faqs.  For past versions of these files and for other languages, consult the page at: https://github.com/athinkra/PastEbolaFAQs.
